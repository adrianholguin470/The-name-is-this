# Wikidata items to create (two items, about 20 minutes)

Log in at wikidata.org (create an account if needed; new accounts can create items immediately). Create the person first, then the firm, then link them. Use the label search when adding a value; the labels below are what to type. Every statement that carries a reference gets "add reference → reference URL" with the URL shown, plus "retrieved" = today.

Why: Google's Knowledge Graph, Bing, Perplexity and several assistants read Wikidata directly. It is the fastest way to tell every engine at once that there is an Adrian A. Holguin in Beverly Hills with these credentials and this firm, distinct from the Southampton founder and the Ecuador coach.
